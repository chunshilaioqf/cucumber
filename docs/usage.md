# 黄瓜 · 添加与使用说明

## 三个概念

1. **配置进程**：由你提供的命令模板驱动（启动/停止/检查/安装依赖），命令以参数数组执行，不穿 shell（安全起见）。
2. **Web 服务**：配置进程的一种，额外携带服务地址（`proto://host:port[/path]`），运行中会出现在「所有服务」页，可一键复制 URL 或调起浏览器。
3. **系统观察进程**：不配置任何命令，仅按「系统观察名」（进程名子串）显示 PID / 状态 / 资源。工具不干预其生命周期。

## 添加进程

1. 「进程」页 →「＋ 添加进程」（或菜单 文件 → 添加进程，快捷键 Ctrl+N）。
2. 填名称、选类型。
3. 命令配置（全部可选）：
   - **启动命令**：默认 spawn 为长驻子进程，工具记录 PID、采集输出；
     若命令是「点火即走」型（如 `systemctl start nginx`），打开「点火即走」开关。
   - **停止命令**：优先生效；未配置时对工具启动的子进程发终止信号（Unix SIGTERM → 5 秒宽限 → 强杀；Windows `taskkill`）。
   - **检查命令**：退出码 0 视为健康。
   - **安装依赖**：手动触发。
4. **环境变量 / 工作目录**：每行一条 `KEY=VALUE`。
5. **服务地址**：每行一条 `http://127.0.0.1:8080/health`（协议支持 tcp/http/https/udp）。
6. **日志源**：每行 `名称 | 文件路径 | 读取命令 | 格式`，路径与命令至少一个；
   格式：`json_lines` / `logfmt` / `bracket`（`[级别] [标签] 时间 消息`）/ `plain`。

## 日志查看

- 「日志」页选择进程与日志源，支持级别多选、标签子串、消息体子串过滤，多条件 AND。
- 分页大小在配置文件 `~/.config/cucumber/config.toml` 的 `log_page_size`（50–1000，默认 100）。
- 打开「跟随」后每 3 秒自动刷新并跳到最新一页（近似 tail -f）。
- 命中关键词黄底高亮；级别（ERROR/WARN/INFO/…）着色。

## 设置（0.3.0）

「设置」页：主题（浅色/深色/跟随系统）、字体族与字号缩放（80%–150%）、窗口背景色（含透明度，作用于应用内绘制层）、系统托盘开关（重启生效）、界面语言（九种，即时切换并持久化）。

## 系统托盘

设置中开启（默认关闭）后，托盘显示黄瓜图标：悬停可见运行统计；右键菜单首行实时显示「运行进程 · 服务 · CPU · 内存」；左键唤起主窗口。Linux 桌面无状态栏协议时自动忽略。

## 自动更新

启动 1 分钟后检查 GitHub Releases；发现新版本时弹窗：立即更新（打开下载页）/ 暂不（下次启动再提示）/ 跳过此版本（不再提示该版本）。

## 平台说明

- Linux：X11 必选；Wayland 会话默认经 XWayland 运行，设置 `WINDUI_BACKEND=wayland` 启用原生后端（此时全局热键不可用，协议限制）。
- macOS 12+、Windows 10+。
- 浏览器调起、命令执行、停止信号等平台差异已收口在 `platform/` 模块。

## 已知限制

- 系统级服务管理为「观察 + 尽力而为信号」；systemctl/launchctl/SCM 级全量管理请配置对应命令。
- 日志编码 v1 仅 UTF-8（GBK 字段预留）。
- 命令执行不经过 shell；需要管道/通配时请显式写 `sh -c "…"`（Unix）/ `cmd /C …`（Windows）。
